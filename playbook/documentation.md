# Documentation Guidelines

## README de agente
Debe responder rapido:
- que resuelve,
- comando principal,
- modo local,
- modo AI si existe,
- costos,
- demo,
- estructura,
- estado actual,
- roadmap.

## Specification
Debe definir el contrato antes del codigo:
- problema,
- objetivo MVP,
- alcance incluido/excluido,
- inputs,
- outputs,
- formato de salida,
- flujo,
- arquitectura,
- componentes,
- criterios de aceptacion,
- decisiones tecnicas,
- futuras extensiones.

## AGENTS.md
Debe orientar a futuros agentes/codex:
- proposito,
- scope,
- non-goals,
- style,
- architecture guidelines,
- gotchas,
- preferred patterns.
