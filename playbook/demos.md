# Demo Guidelines

## Objetivo
Cada agente debe incluir una demo minima, reproducible y versionable.

## Reglas
- La demo debe mostrar el output real del agente.
- Usar rutas genericas en README.
- Evitar depender de archivos privados para entender la demo.
- Si la demo usa AI, documentar costo aproximado.
- Si el output puede variar, guardar una version de referencia.

## Nombres recomendados
```text
RFC_DEMO.md
REPORT_DEMO.md
OUTPUT_DEMO.md
```

## Seccion README
```md
## Demo
Este repositorio incluye una salida de ejemplo generada con el comando principal:

- [`RFC_DEMO.md`](RFC_DEMO.md)
```
