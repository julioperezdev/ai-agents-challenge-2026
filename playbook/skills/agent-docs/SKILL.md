# Agent Docs

## Proposito
Mantener documentacion consistente y lista para publicar.

## Checklist
- [ ] README explica que resuelve.
- [ ] README muestra comando principal recomendado.
- [ ] README documenta modo local y modo AI.
- [ ] README incluye costos si usa AI.
- [ ] README referencia demo versionable.
- [ ] Specification refleja el codigo real.
- [ ] AGENTS.md captura scope, non-goals y gotchas.

## Reglas
- Usar rutas genericas en comandos publicos.
- No dejar placeholders sin explicar.
- No documentar features que no existen.
- Actualizar README general si cambia el estado del agente.
